# Commonplace private spending tracker

A single-user spending tracker with password sign-in, AI expense drafting, receipt image extraction, and persistent Supabase Postgres storage.

## Run locally

Requires Python 3.9 or newer. Without `DATABASE_URL`, the app uses a local SQLite file under `data/`. Optional AI drafting requires a server-side API key:

```sh
export OPENAI_API_KEY="your-private-api-key"
python3 server.py
```

Open http://127.0.0.1:3000. For local work, sign-in is disabled unless `APP_PASSWORD` is set. Never put provider keys in `index.html` or commit them.

## Deploy a free online version

The included `render.yaml` configures a free Render web service. Render's service will sleep after 15 minutes without traffic and can take about a minute to wake. Its filesystem is temporary, so this app stores lasting data in Supabase instead.

1. Create a Supabase project on its Free plan.
2. In Supabase, open **Connect**, choose **Session pooler**, and copy the connection string. Replace the password placeholder with your database password. Keep the connection string private.
3. Put the project in a private GitHub repository and connect that repository to Render as a Blueprint. Render reads `render.yaml`.
4. In Render's Environment settings, set `DATABASE_URL` to the Supabase session-pooler string, `APP_PASSWORD` to a strong password of at least 12 characters, and `OPENAI_API_KEY` to your separate API key. `SESSION_SECRET` is generated by the Blueprint.
5. Deploy, then open the generated `onrender.com` address and sign in with `APP_PASSWORD`.

The server uses TLS for the database connection and creates the expense/settings tables with Row Level Security enabled and direct Data API grants revoked for `anon` and `authenticated`; the website accesses data only through its password-protected server. The Supabase database password and OpenAI API key stay in Render's server-side environment settings.

## Limits and data handling

Supabase Free currently includes 500 MB of database storage. Free projects may pause after a week of low activity; paused project data remains restorable for up to one year. Free projects do not include automatic database backups, so periodically export any expenses you care about. Render's free web service sleeps after 15 minutes of inactivity. These free tiers are useful for trying the prototype, not as the only copy of important financial records.

Approved expenses and settings are stored in Supabase Postgres. Receipt images are not stored by this app; when you upload one, it is sent to the configured OpenAI API for extraction and then discarded by the app. The app asks you to review details before saving an expense. AI API usage is billed separately by OpenAI.
